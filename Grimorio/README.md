# ⚔️ Grimório das Missões

Um sistema gamificado de organização pessoal com 6 modos interativos para gerenciar sua rotina como se fosse um jogo RPG.

## 🎮 Sobre o Projeto

O **Grimório das Missões** é um aplicativo web que transforma sua rotina em uma jornada épica. Com uma interface estilosa e funcionalidades completas, você pode gerenciar tarefas, acompanhar progresso e manter tudo organizado.

### ✨ Funcionalidades

- **🏰 Sistema de Saves**: Crie múltiplos perfis com nomes personalizados
- **🎯 6 Modos de Jogo**:
  - **Game**: Sistema RPG com XP, níveis, skills e loja
  - **📌 Mural**: Post-its visuais fixados em um mural
  - **✅ Lista**: Tarefas com checkboxes
  - **⏱️ Timer**: Cronômetros com prazo ou tempo regressivo
  - **📝 Diário**: Editor estilo Word com formatação
  - **🖼️ Galeria**: Museu de fotos com upload do dispositivo
- **👁️ Modo Leitura**: Visualize sem editar
- **💾 Persistência**: Todos os dados salvos no localStorage

### 🛠️ Tecnologias

- HTML5
- CSS3 (com animações e temas escuros)
- JavaScript (Vanilla JS)
- Font Awesome (ícones)
- Google Fonts (Cinzel + Inter)

### 🚀 Como Usar

1. Clone o repositório
2. Abra o `index.html` no navegador
3. Crie um save e escolha seu modo
4. Comece sua jornada!

### 🎯 Funcionalidades Detalhadas

#### Modo Game
- Perfil personalizável (nome, bio, avatar)
- Sistema de XP e níveis
- Skills customizáveis
- Loja com itens resgatáveis

#### Modo Timer
- Prazo com data e hora específica
- Cronômetro regressivo com segundos
- Alertas visuais quando o tempo está acabando

#### Modo Diário
- Editor com formatação (negrito, itálico, listas)
- Múltiplas páginas
- Interface de caderno com linhas

### 🔒 Privacidade

Todos os dados são armazenados localmente no seu navegador. Nenhuma informação é enviada para servidores.
