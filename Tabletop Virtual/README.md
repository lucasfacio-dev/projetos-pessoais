# 🎲 Tabletop Virtual

Um tabletop RPG virtual leve e intuitivo para mestres e jogadores, desenvolvido em HTML, CSS e JavaScript puro. Perfeito para campanhas de RPG de mesa online.

## ✨ Funcionalidades

- 📜 **Sistema de Páginas/Cenas** - Crie e gerencie múltiplas cenas com nomes personalizados
- 🗺️ **Upload de Mapas** - Adicione imagens como mapa de fundo
- 🎭 **Tokens** - Crie tokens redondos ou PNG transparentes com suporte a arrastar e soltar
- 📦 **Inventário** - Armazene tokens e arraste diretamente para o mapa
- 📊 **Ficha do Personagem** - Duplo clique no token para abrir:
  - Nome, Classe, Raça e Observações
  - Barra de Vida com bônus editável
  - Atributos personalizáveis (tags estilo)
  - Inventário/Hotbar com itens (imagem ou texto)
- 🔲 **Grid** - Grade sobreposta para facilitar o posicionamento
- 🔍 **Zoom e Pan** - Navegue pelo mapa com zoom e arraste
- 👁️ **Modo Leitura** - Visualização limpa com navegação entre cenas
- 💾 **Salvamento Automático** - Todos os dados são salvos no localStorage
